## 🛠️ Устранение неполадок

### Проблемы с подключением к БД
1. Проверьте настройки в `config.php`
2. Убедитесь, что таблица `seo_monitoring` создана
3. Проверьте права доступа к БД

### Ошибки при обновлении файлов
1. Проверьте права записи в корневую папку сайта
2. Убедитесь, что файлы `index.html`, `sitemap.xml` доступны для записи
3. Проверьте логи в админ-панели

### Проблемы с мониторингом
1. Проверьте настройки cron
2. Убедитесь, что PHP доступен из командной строки
3. Проверьте права доступа к файлам
