# 🔒 Безопасность конфигурации

## ⚠️ ВАЖНЫЕ МЕРЫ БЕЗОПАСНОСТИ

### 1. Защита конфигурационного файла

Файл `admin/config.php` содержит чувствительные данные для подключения к базе данных. 

**НЕОБХОДИМО:**
- ✅ Файл `admin/config.php` защищен через корневой `.htaccess` от прямого доступа
- ✅ Данные БД больше не хранятся в открытом виде в коде
- ✅ Все подключения к БД теперь используют централизованную функцию

### 2. Дополнительные меры безопасности

**Рекомендуется:**

1. **Переместить config.php за пределы веб-директории:**
   ```bash
   # Создать папку вне веб-директории
   mkdir /var/www/secure_config
   mv admin/config.php /var/www/secure_config/
   
   # Обновить путь в файлах
   require_once '/var/www/secure_config/config.php';
   ```

2. **Использовать переменные окружения:**
   ```php
   // В config.php
   define('DB_HOST', $_ENV['DB_HOST'] ?? 'localhost');
   define('DB_USERNAME', $_ENV['DB_USERNAME'] ?? 'default_user');
   define('DB_PASSWORD', $_ENV['DB_PASSWORD'] ?? 'default_password');
   ```

3. **Настроить права доступа:**
   ```bash
   chmod 600 /var/www/secure_config/config.php
   chown www-data:www-data /var/www/secure_config/config.php
   ```

### 3. Проверка безопасности

**Регулярно проверяйте:**

- [ ] Файл `config.php` недоступен через браузер
- [ ] Логи сервера не содержат чувствительных данных
- [ ] Резервные копии не включают конфигурационные файлы
- [ ] Права доступа к файлам настроены правильно

### 4. Мониторинг

**Настройте мониторинг:**
- Логирование попыток доступа к защищенным файлам
- Уведомления о подозрительной активности
- Регулярные проверки целостности файлов

### 5. Обновление данных

**При смене данных БД:**
1. Обновите только файл `config.php`
2. Проверьте подключение через админку
3. Убедитесь, что все функции работают корректно

---

## 📋 Чек-лист безопасности

- [ ] `admin/config.php` защищен через корневой `.htaccess`
- [ ] Данные БД не видны в исходном коде
- [ ] Все файлы используют централизованное подключение
- [ ] Ошибки не раскрывают чувствительную информацию
- [ ] Резервные копии не содержат конфигурационных данных
- [ ] Права доступа настроены правильно
- [ ] Мониторинг безопасности настроен
