# 🔧 Устранение проблем с админ-панелью

## Проблема: "Ошибка подключения к базе данных"

Если вы видите эту ошибку в админ-панели, это означает, что система не может подключиться к MySQL базе данных.

### 🔍 Диагностика

1. **Перейдите в админ-панель:** `https://tonirovka.kh.ua/admin/`
2. **Проверьте раздел "📋 Системная информация"** в настройках
3. **Статус подключения к БД** должен показывать "✅ Подключено"

### 🛠️ Решения

#### Вариант 1: Проверка настроек БД (рекомендуется)
1. Войдите в админ-панель
2. Перейдите в раздел "⚙️ Настройки"
3. Проверьте параметры подключения к БД в разделе "📋 Системная информация"

#### Вариант 2: Ручная настройка БД
Если автоматическое подключение не работает:

1. **Проверьте файл `admin/config.php`**
2. **Убедитесь в правильности параметров:**
   - `DB_HOST` - хост базы данных
   - `DB_USERNAME` - имя пользователя
   - `DB_PASSWORD` - пароль
   - `DB_DATABASE` - название базы данных
3. **Проверьте, что база данных существует** на сервере

#### Вариант 3: Обращение к хостинг-провайдеру
Если ни один из способов не работает:

1. **Свяжитесь с поддержкой хостинга**
2. **Сообщите о проблеме:** "Не удается подключиться к MySQL базе данных"
3. **Попросите проверить настройки БД** и права доступа

2. **Проверьте раздел "📋 Системная информация"** в настройках

### 🚨 Частые проблемы

#### Проблема: "Ошибка подключения к БД"
**Решение:** Проверьте параметры в `admin/config.php` и убедитесь, что БД существует

#### Проблема: "Таблица не найдена"
**Решение:** Запустите миграцию БД через админ-панель или создайте таблицы вручную

#### Проблема: "Не удается обновить сайт"
**Решение:** Проверьте права на запись файла `index.html` (должны быть 644 или 666)

#### Проблема: "Ошибка загрузки изображений"
**Решение:** Проверьте права на папку `images` (должны быть 755) и размер файлов

### 📞 Поддержка

Если проблемы остаются:
1. **Сделайте скриншот** результатов диагностики из раздела "📋 Системная информация"
2. **Обратитесь к хостинг-провайдеру** с описанием проблемы
3. **Укажите URL:** `https://tonirovka.kh.ua/admin/`
4. **Приложите логи** из раздела "📋 Логи администратора"

### 🔐 Безопасность

После настройки админ-панели:
1. **Измените пароль по умолчанию** в разделе настроек
2. **Регулярно делайте резервные копии** через админ-панель
3. **Не публикуйте логины и пароли** в открытом доступе
4. **Следите за логами** для выявления подозрительной активности

### 🔄 Резервное копирование

Система автоматически создает резервные копии:
- **Ежедневно** - автоматические бэкапы БД
- **При изменениях** - бэкапы перед важными операциями
- **Вручную** - через раздел "⚙️ Настройки" → "Резервные копии"
