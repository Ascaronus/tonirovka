# 🔧 Админ-панель tonirovka.kh.ua

## 📋 Описание

Админ-панель для управления одностраничным сайтом `tonirovka.kh.ua`. Позволяет управлять контентом, ценами, галереей и настройками сайта без необходимости редактирования кода.

**Версия:** 3.2 (31 Июля 2025)

## 🚀 Доступ к админ-панели

**URL:** `https://tonirovka.kh.ua/admin/`

**Логин по умолчанию:**
- **Пользователь:** `admin`
- **Пароль:** `tonirovka2025`

## Данные и источник истины

**Источник истины — MySQL.** Контент, цены, галерея и плёнки хранятся в базе данных. Файлы в `data/` (content.json, prices.json, gallery.json) и `langs/uk.json`, `langs/ru.json` генерируются из БД при сохранении в админке. Не редактируйте эти JSON вручную — при следующем сохранении они будут перезаписаны из БД.

## 📊 Структура данных

Все данные сохраняются в JSON файлах в папке `../data/`:

```
data/
├── content.json       # Контент сайта
├── prices.json        # Услуги и цены
├── gallery.json       # Галерея изображений
├── films.json         # Типы пленок
└── settings.json      # Настройки системы
```

## 🛠️ Технические требования

- **PHP:** 7.4 или выше
- **Веб-сервер:** Apache/Nginx
- **Права записи:** Папка `data/` должна быть доступна для записи
- **Поддержка сессий:** PHP sessions должны быть включены
