# 🌐 Language Files (JSON Localization)

Эта папка содержит JSON файлы с переводами для всех языков сайта.

## 📁 Структура файлов

- `uk.json` - Украинский язык
- `ru.json` - Русский язык

## 🔄 Автоматическая генерация

JSON файлы **автоматически генерируются** после каждого сохранения в админ панели:
- `content.php` - при изменении контента (hero, FAQ, contacts, footer)
- `prices.php` - при изменении цен
- `films.php` - при изменении пленок
- `gallery.php` - при изменении галереи

## 🚀 Использование

Эти JSON файлы могут быть использованы:
1. **Frontend JavaScript** - для динамической загрузки переводов
2. **API** - для передачи локализованного контента
3. **Static Site Generation** - для предрендеринга контента
4. **Mobile Apps** - для использования переводов

## ⚠️ Важно

- **Не редактируйте JSON файлы вручную!** Они автоматически перезаписываются при сохранении в админ панели.
- Все изменения должны вноситься через админ панель.
- Функция генерации находится в `admin/lang_functions.php`.
